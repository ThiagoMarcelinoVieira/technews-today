# TechNews Today

Este repositório contém o projeto "TechNews Today", uma página principal de um portal de tecnologia. Esta atividade prática foi desenvolvida como parte do curso de Desenvolvimento de Sistemas do SENAI 118.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Utilizado para a marcação semântica e estruturação do conteúdo.
* **CSS3:** Utilizado para a estilização, efeitos visuais e responsividade da página.

## 📁 Estrutura do Projeto
O projeto é composto pelos seguintes arquivos principais:
* `desafio10a.html`: Contém a estrutura da página, incluindo o cabeçalho, artigo de destaque, seção de vídeo e um formulário de newsletter.
* `10a_desafio.css`: Contém as regras de estilo, incluindo fundos, transições e regras de responsividade.

## ✨ Funcionalidades Implementadas
* **Design Responsivo:** A página utiliza CSS Grid e Media Queries para adaptar o layout de uma para duas colunas em telas maiores (`min-width: 768px`).
* **Estilização Moderna:** Aplicação de fundos com gradientes lineares, efeito *glassmorphism* (através de `backdrop-filter: blur`) e cantos arredondados.
* **Elementos Interativos Nativos:** Utilização das tags HTML `<details>` e `<summary>` para criar seções de conteúdo expansível sem necessidade de JavaScript.
* **Integração Multimídia:** Incorporação de um vídeo do YouTube através da tag `<iframe>`.
* **Formulário de Inscrição:** Uma seção de newsletter estruturada, que inclui campos de texto, uma lista suspensa (`<select>`) e uma caixa de seleção (`checkbox`).

## ⚙️ Como Executar o Projeto
1. Faça o clone deste repositório para o seu ambiente local:
   ```bash
   git clone https://github.com/ThiagoMarcelinoVieira/technews-today.git
   ```
2. Navegue até a pasta onde o projeto foi salvo.
3. Dê um duplo clique no arquivo `desafio10a.html` para abri-lo em qualquer navegador web moderno (Chrome, Edge, Firefox, etc.).
